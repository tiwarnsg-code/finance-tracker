💰 Finance Tracker — คู่มือการติดตั้ง

ทำตามขั้นตอนนี้เพื่อเชื่อมต่อแอพกับ Google Sheets ใช้เวลาประมาณ 10 นาที

1
สร้าง Google Spreadsheet ใหม่
  1. ไปที่ sheets.google.com แล้วสร้าง Spreadsheet ใหม่
  2. ตั้งชื่อว่า "Finance Tracker" (หรือชื่ออะไรก็ได้)
  3. คัดลอก Spreadsheet ID จาก URL
    URL ตัวอย่าง: https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit
    ส่วนที่เป็น ID คือข้อความยาวๆ ตรงกลาง URL
2
สร้าง Google Apps Script
  1. ใน Spreadsheet ที่สร้าง ไปที่เมนู Extensions → Apps Script
  2. จะเปิดหน้าต่าง Apps Script ขึ้นมา
  3. ลบโค้ดเดิมทั้งหมดออก แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ Code.gs มาวาง
  4. กด Ctrl+S (หรือ Cmd+S บน Mac) เพื่อบันทึก
✅ ไฟล์ Code.gs อยู่ในโฟลเดอร์ finance-tracker บน Desktop ของคุณ
3
Deploy Web App
  1. ใน Apps Script คลิกปุ่ม "Deploy" (มุมบนขวา) → เลือก "New deployment"
  2. คลิกไอคอน ⚙️ ข้าง "Select type" → เลือก "Web app"
  3. ตั้งค่าดังนี้:
    • Description: Finance Tracker v1
    • Execute as: Me (ชื่อบัญชี Google ของคุณ)
    • Who has access: Anyone
  4. คลิก "Deploy"
  5. ระบบจะขอ Authorization — คลิก "Authorize access" และอนุญาตทั้งหมด
  6. คัดลอก Web app URL ที่แสดงขึ้นมา
⚠️ URL จะมีหน้าตาแบบนี้: https://script.google.com/macros/s/AKfycby.../exec
✅ เก็บ URL นี้ไว้ให้ดี จะใช้ในขั้นตอนต่อไป
4
เปิดแอพและตั้งค่า
  1. เปิดไฟล์ index.html ในโฟลเดอร์ finance-tracker
  2. วาง Web app URL ที่คัดลอกไว้ในช่องที่กำหนด
  3. คลิก "เชื่อมต่อและเริ่มใช้งาน"
  4. แอพจะสร้าง Sheets ที่จำเป็นใน Google Spreadsheet ของคุณโดยอัตโนมัติ
✅ เสร็จแล้ว! ข้อมูลทั้งหมดจะถูกเก็บใน Google Sheets และสามารถเข้าถึงได้จากทุกที่
✓
การใช้งานข้ามอุปกรณ์

เนื่องจากข้อมูลถูกเก็บใน Google Sheets คุณสามารถ:

  • เปิดแอพบนคอมพิวเตอร์เครื่องอื่น โดยคัดลอกโฟลเดอร์ finance-tracker ไปด้วย
  • ใช้ Google Drive เพื่อ Sync โฟลเดอร์ข้ามอุปกรณ์
  • อัพโหลดไฟล์ไปยัง GitHub Pages หรือ Netlify เพื่อเข้าถึงผ่าน URL ได้เลย
💡 วิธีง่ายที่สุด: เปิด Google Drive บนทุกเครื่อง แล้วใส่โฟลเดอร์ finance-tracker ใน Drive — จะ Sync อัตโนมัติ
